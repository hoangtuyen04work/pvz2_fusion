# Imported zombie animation sources

Imported on 2026-10-02 from:

- https://github.com/jiangnangame/New-Plants-vs-Zombies-JavaScript
- https://github.com/FregD156/PvZ_Assets

Every GIF found for the selected zombie folders was converted frame-by-frame to transparent PNG sequences for Unity. This includes normal movement, attack, death, lost-head and special animations such as pole vaulting, balloon drop, Jack-in-the-Box opening, dancing/summoning, dolphin jumping and snorkel transitions.

Original sound effects for these zombies were copied from the extracted `PvZ_Assets` set into `Resources/Sounds/Zombies/ImportedOriginal`.

The JiangNanGame English license is preserved as `JIANGNAN_LICENSE.md`. Plants vs. Zombies artwork and audio remain property of PopCap Games / Electronic Arts.
