# Cherry Bomb explosion source

`ExplosionCloud.png` and `ExplosionPowie.png` come from the `particles` folder of:

https://github.com/FregD156/PvZ_Assets

The Unity implementation follows the `particles/Powie.xml` emitter timing and layering.
The repository states that these are extracted assets from the original macOS release of Plants vs. Zombies; PopCap/EA retains the original asset rights.
