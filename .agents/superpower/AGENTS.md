# Project Rules

All agents working in this repository must read and follow
`.agents/superpower/PROCESS.md` before analyzing, modifying code, or concluding work.
These are default mandatory rules unless a user instruction directly conflicts.

Required: define scope; inspect existing code; make a verifiable plan; make only the
smallest relevant change; validate honestly; preserve unrelated user work.

UI RULE: All UI changes must follow the Plants vs. Zombies UI rules in the process file.
ARCHITECTURE RULE: All code changes must follow its game-programming and modern
architecture rules, including clear ownership, lifecycle safety, testability, and
separation between game logic and UI.
